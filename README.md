# FitForge iOS

FitForge is a native iOS fitness app project built with Swift.

The repository contains the foundation for a mobile fitness application, including the main app target, unit tests, UI tests, and Xcode project setup.

## Why This Project Exists

The goal of FitForge is to build a clean iOS app foundation for tracking fitness activity, organizing workout-related flows, and experimenting with native mobile development patterns.

This project is part of my broader work across mobile apps, full-stack systems, and user-facing product development.

## Tech Stack

- Swift
- iOS
- Xcode
- XCTest
- UI Testing

## Repository Structure

- `FitForge/` - main iOS application source code
- `FitForgeTests/` - unit test target
- `FitForgeUITests/` - UI test target
- `FitForge.xcodeproj/` - Xcode project file

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/sutejym122/FitForge-iOS.git
cd FitForge-iOS
```

2. Open the project in Xcode:

```bash
open FitForge.xcodeproj
```

3. Select an iPhone simulator.
4. Build and run the app.
